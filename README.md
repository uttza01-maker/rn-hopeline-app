## 📝 เกี่ยวกับโปรเจกต์ (About The Project)
**RN Hopeline App** เป็นแอปพลิเคชันมือถือที่พัฒนาด้วย **React Native (Expo)** เพื่อรวบรวมเบอร์โทรศัพท์สายด่วนฉุกเฉินและบทความความรู้ในการเอาตัวรอด/ปฐมพยาบาลเบื้องต้นในประเทศไทย ช่วยให้ผู้ใช้งานสามารถค้นหาและกดโทรออกไปยังหน่วยงานสำคัญต่างๆ ได้อย่างรวดเร็วในสถานการณ์คับขัน

An emergency hotline and first-aid knowledge mobile application built with **React Native (Expo)**. It provides quick access to essential Thai emergency numbers categorized by services, alongside useful articles for safety and first-aid guidelines.
